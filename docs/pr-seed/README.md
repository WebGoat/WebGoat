# Safe PR Seed

This folder is a safe pull request seed for testing repository and PR review tooling.

It intentionally contains review defects in documentation quality, consistency, and evidence mapping. It does **not** add exploitable code or real security weaknesses to the running application.

## Intended Use

1. Create a PR containing the files in this folder.
2. Ask the other project to review the PR.
3. Check whether it identifies the seeded review issues.

## Review Defect Themes In This Seed

- inconsistent severity mapping
- incorrect evidence paths
- duplicated identifiers
- unsupported claims
- missing mitigation guidance
- mismatched scenario mapping

Do not treat these files as canonical benchmark data.
