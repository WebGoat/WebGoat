# Report Update Checklist

Replace every highlighted placeholder in the generated Word report with verified evidence:

- Group members, IDs and signatures
- Repository URL and baseline commit
- Final Compose services, ports and image tag
- Four actual vulnerabilities and exact source locations
- Before/after screenshots and safe test descriptions
- Regression test names and outputs
- SAST counts and rule identifiers
- Dependency-Check, Gitleaks and Trivy outputs
- Failed/passed GitHub Actions URLs
- Secret variable names without values
- Member-specific commits, pull requests and reviews
- Accurate AI disclosure

Update the Word table of contents and export the final report as PDF.
