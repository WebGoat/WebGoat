== Stage 4: the database is no longer enough

The blog adds a pepper with this construction:

[source,text]
----
argonResult = Argon2id(password, uniqueSalt, parameters)
storedVerifier = HMAC-SHA-256(key=pepper, data=argonResult)
----

The database stores the salt, Argon2id parameters, HMAC algorithm, and final verifier. It does not store `argonResult` or the pepper.

You obtained the complete database through a simulated SQL injection. Decide whether the dump contains everything required to verify offline guesses and name the missing value.

A pepper is a shared secret. It adds protection only when a database attacker cannot obtain it. It does not replace a password KDF, unique salts, strong passwords, or access controls.
