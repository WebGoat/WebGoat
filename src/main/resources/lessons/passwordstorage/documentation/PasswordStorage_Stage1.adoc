== Stage 1: "We hash our passwords"

The first blog version stores `SHA-256(UTF-8(password))`. SHA-256 protects data integrity, but it is designed to run fast. An attacker can test many password guesses after stealing the hashes.

The dump also reveals that Alice and Bob have the same hash. Without salts, equal passwords produce equal hashes.

Use the supplied wordlist tool to test candidates against Maria's hash, then submit her password.

The tool runs in your browser. It performs the same work that an offline attacker could perform with the database dump.
