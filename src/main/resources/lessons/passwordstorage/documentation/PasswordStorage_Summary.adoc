== What each measure changes

[cols="1,2,2",options="header"]
|===
|Measure |What it protects against |What it does not solve

|Unique salt
|Precomputed tables and reuse of work across accounts. It also hides password equality.
|Offline guessing of weak passwords.

|Argon2id
|Cheap candidate testing. Its configurable memory and time costs raise the cost of each guess.
|A weak password becoming unguessable, or theft of every required verification secret.

|Pepper
|A database-only compromise when the pepper remains secret and separately controlled.
|A compromise that also reaches the pepper, or an application runtime that can use it.
|===

Choose current parameters for the application's hardware and capacity. Measure authentication latency and memory use, and review the configuration as hardware and guidance change.

Further reading: https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html[OWASP Password Storage Cheat Sheet,window=_blank] and https://www.rfc-editor.org/rfc/rfc9106.html[RFC 9106,window=_blank].
