== Stage 3: make each guess cost more

The blog replaces SHA-256 with Argon2id. Argon2id is a password key derivation function. Its memory and time costs make each candidate test more expensive.

The encoded value uses the PHC string format:

[source,text]
----
$argon2id$v=19$m=19456,t=2,p=1$salt$output
----

The fields identify the algorithm, version, memory in KiB, iterations, parallelism, salt, and derived output. None of those fields need to be secret.

Read Maria's encoded value and submit its parameters. Also choose the accurate cost comparison.

There is no universal "guesses per second" value. Hardware, parameters, libraries, and available memory all affect the result. The stable comparison is that this Argon2id configuration requires 19 MiB of working memory and two passes for each guess, while one SHA-256 digest has no comparable memory cost.
