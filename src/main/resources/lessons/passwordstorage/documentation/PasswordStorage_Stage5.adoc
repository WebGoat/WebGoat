== Stage 5: a pepper needs a separate trust boundary

The blog deployment accidentally publishes a backup of `application.properties`. Retrieve the file and inspect its contents.

If the backup exposes the pepper, combine it with the database record and the training wordlist. The bounded attack tool tests at most five candidates. Submit Maria's recovered password.

Calling a hardcoded string a pepper does not protect anything when the same compromise exposes both the database and configuration. Production systems should keep the secret outside the database with separate access controls, plan for rotation, and treat an application-runtime compromise as a different threat from a database-only leak.
