=== Escalate: Read the flag

The cat gallery looks innocuous: when you type a name in the search box it simply runs
`grep $title images/*.txt` on Unix or `findstr /I $title images\*.txt` on Windows and shows the
matching cats.
Unfortunately the search term is injected into the shell command verbatim.
Add a separator such as `;`, `&&`, or `&`. The shell executes whatever else you append under the
service account.

Attackers follow this exact pattern to dump environment variables, API keys, and other secrets once they uncover a command injection primitive.
