=== Safety First

These exercises execute real commands on the machine running WebGoat. If you are running the
standalone JAR on your workstation, a malformed input could leave processes running or modify
files. We highly recommend using the official `webgoat/webgoat` Docker image for this lesson so
you can remove the container after experimenting. The status panel below reports whether this
WebGoat instance was started from that image.

Type the sentence below to acknowledge the risk and continue:

`I understand commands will execute`

The command endpoints remain locked until you submit this acknowledgement. Resetting the lesson
locks them again.
