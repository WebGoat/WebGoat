=== Filter bypass: Leak the API key

Operations noticed people chaining commands and added a quick denylist: the server now strips
`;`, `&&`, and `|` from your cat search before sending it to the shell. The diags console still runs
`grep $title images/*.txt` or the Windows `findstr` equivalent, so you need syntax that survives.

At startup the lesson stores an API key for you in
`command-injection/task4/<username>/api-key.txt`. Bypass the filter, read the file, and enter the key
below to finish the task.

On Unix, try command substitution such as `$(...)` or inject a newline. On Windows, the filter
removes `&&` but misses a single `&`, and `type` can read the key file.
