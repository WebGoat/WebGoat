Delivery variant: checked-in project configuration

Create an empty folder and save one of these files in it. Opening that folder in the assistant registers the server without anyone running a command.

.mcp.json (Claude Code)

{
  "mcpServers": {
    "invoicehelper": { "type": "http", "url": "" }
  }
}

.vscode/mcp.json (VS Code)

{
  "servers": {
    "invoicehelper": { "type": "http", "url": "" }
  }
}

.cursor/mcp.json (Cursor)

{
  "mcpServers": {
    "invoicehelper": { "url": "" }
  }
}

When you are done: remove the server

The server stays registered after you close the lesson. Remove it so the poisoned tools are not available in your next, real session:

claude mcp remove invoicehelper
gemini mcp remove invoicehelper
codex mcp remove invoicehelper

For Claude desktop, delete the invoicehelper entry from claude_desktop_config.json and restart the app. For the delivery variant, delete the folder with the checked-in configuration.
