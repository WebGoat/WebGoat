== Security keys, passkeys and WebAuthn

Passwords can be guessed, reused, leaked and phished. One-time codes sent by SMS or generated by an app
improve this, but an attacker running a look-alike site can still ask the victim for the code and use it
immediately.

*FIDO2* replaces shared secrets with public key cryptography. It consists of two specifications:

* *WebAuthn* (W3C): the JavaScript API (`navigator.credentials.create()` / `navigator.credentials.get()`)
  that a website uses to talk to the browser, and the data formats the server receives.
* *CTAP2* (FIDO Alliance): the protocol the browser or operating system uses to talk to an
  authenticator, for example a security key over USB, NFC or Bluetooth.

For every website the authenticator creates a new key pair. The private key never leaves the
authenticator; the website only stores the public key. Because the browser tells the authenticator
which site is asking, and puts the origin into the signed data, a credential for `goatbank.example`
cannot be used on `goatbank-login.example`. This makes WebAuthn _phishing resistant_.

=== It is only as strong as the server

The browser and the authenticator do their part, but *the relying party (the website) has to verify
everything it receives*. The specification lists more than twenty verification steps for registration
and authentication. Developers who build this themselves, or who use a library incorrectly, can easily
leave one of them out. A single missing check can turn "unphishable" authentication into an account
takeover.

=== Lesson goals

After this lesson you will:

* understand authenticators, security keys and passkeys, and the data exchanged during the
  *registration* and *authentication* ceremonies;
* exploit a registration flaw that binds your security key to someone else's account;
* exploit an authentication flaw that allows replaying a captured login;
* know which other implementation mistakes to look for, and how to prevent them;
* (bonus) register and sign in with a real roaming security key against a server that performs all checks.
